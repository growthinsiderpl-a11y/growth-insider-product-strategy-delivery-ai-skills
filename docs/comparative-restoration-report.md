# Comparative Restoration Report

## Summary

This repository restores product capability from the immutable product baseline into a public release-candidate package aligned to Growth Insider identity, modern Agent Skills packaging, and strict product scope ownership.

## What was restored

- `227` baseline rows were reauthored into product hubs, playbooks, docs, and examples
- `21` baseline rows were rebuilt as deterministic local tools
- `7` baseline rows were merged, replaced, or converted into package-level public artifacts
- `102` baseline rows were retired with reason because they belong to marketing, deep engineering implementation, legacy bundle structure, or non-public packaging concerns

## Restoration principles

- no copied literature chapters or persona role-play framing
- no opaque PMF scores, hidden prioritization defaults, or sprint health scores
- no mandatory network integration in the core package
- no legacy author references outside validator guardrails
- no Jira or Atlassian mutation guidance without explicit confirmation rules

## Result

The restored package centers on product strategy, discovery, PMF evidence, analytics, prioritization, requirements, delivery planning, product-led retention, governance, and product-to-engineering handoff.
