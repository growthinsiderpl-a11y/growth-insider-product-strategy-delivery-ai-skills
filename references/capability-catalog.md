## Tools

- `calculate-experiment-sample-size` -> `scripts/analytics/calculate_experiment_sample_size.py`: Estimate per-variant sample sizes for product experiments from explicit assumptions.
- `calculate-product-metrics` -> `scripts/analytics/calculate_product_metrics.py`: Calculate explicit activation, engagement, retention, and monetization metrics from supplied counts.
- `calculate-retention-cohorts` -> `scripts/analytics/calculate_retention_cohorts.py`: Calculate cohort retention tables from explicit retained counts by period.
- `evaluate-evidence-rubric` -> `scripts/discovery/evaluate_evidence_rubric.py`: Check completeness and balance of product evidence without generating a fake PMF score.
- `compare-prioritization-options` -> `scripts/discovery/compare_prioritization_options.py`: Compare prioritization options using only user-supplied criteria and weights.
- `validate-user-story` -> `scripts/requirements/validate_user_story.py`: Validate whether a user story is outcome-linked, testable, and ready for refinement.
- `validate-acceptance-criteria` -> `scripts/requirements/validate_acceptance_criteria.py`: Validate whether acceptance criteria are observable, complete, and categorized.
- `validate-roadmap-consistency` -> `scripts/delivery/validate_roadmap_consistency.py`: Check roadmap items for objective alignment, dependency clarity, and release sequencing gaps.
- `validate-okr-cascade` -> `scripts/delivery/validate_okr_cascade.py`: Check whether objectives, key results, and initiatives form a complete cascade.
