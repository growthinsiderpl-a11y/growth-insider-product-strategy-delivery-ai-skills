# Support

For questions about this repository, compatibility notes, product-workflow feedback, or commercial inquiries, contact [support@growthinsider.pl](mailto:support@growthinsider.pl).

Website: [https://growthinsider.pl/en/](https://growthinsider.pl/en/)

This package is a local Agent Skills release candidate. Public GitHub issue URLs are not published until a repository is created.

When contacting support, include:

- the Skill name and version from `SKILL.md` / `manifest.json`
- whether the question is about routing, a hub or playbook, a deterministic tool, or package documentation
- the product decision or artifact you were trying to produce
- any local validator or test output that clarifies the issue

Do not send secrets, production credentials, or private customer data in support messages.
